# Regression Checklist

## Navigation

- [ ] Every ladder works from bottom to top
- [ ] Players can climb back down
- [ ] Bridges connect on both ends
- [ ] Stairs do not overlap walls, props, or ceilings
- [ ] Elevated routes reconnect instead of ending unexpectedly
- [ ] Ground routes remain open for normal avatar sizes

## Object placement

- [ ] Generator is on a stable floor
- [ ] Generator has enough interaction space
- [ ] Props do not float
- [ ] Props do not overlap structures
- [ ] Props do not block stairs, ladders, doors, or spawn areas

## Disaster systems

- [ ] Flood resets after the event
- [ ] Flood does not restart without a new trigger
- [ ] Flood and ground lava cannot run together
- [ ] Meteors spawn above the tallest structure
- [ ] Crusher stops at the intended roof level
- [ ] Geysers begin at ground level
- [ ] Destruction does not leave invisible collision behind

## Round flow and UI

- [ ] One player can start a round
- [ ] Spectating begins correctly after death
- [ ] Results show the correct survivors
- [ ] Warning cards fit long disaster names
- [ ] Text remains readable on phone-size layouts
- [ ] No placeholder or debug text is visible

## Final pass

- [ ] Complete one full round on each map
- [ ] Repeat all previously failed cases
- [ ] Record pass or fail results
- [ ] Capture screenshots for remaining issues
- [ ] Confirm no new critical or high-severity issue was introduced
