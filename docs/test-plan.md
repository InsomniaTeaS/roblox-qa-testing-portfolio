# Test Plan

## Purpose

The goal of this pass was to find problems that would make a round feel unfair, confusing, or unfinished.

## Scope

I tested:

- Ladders, stairs, bridges, and elevated routes
- Generator and prop placement
- Collision and clipping
- Flood, lava, meteor, crusher, and other disaster behavior
- Round flow and spectating
- Warning cards on smaller screens

I did not test payment processing, large-scale server load, or advanced exploit protection.

## Environment

- Roblox Studio play test
- Desktop keyboard and mouse
- Mobile device emulator
- Single-player and small multiplayer sessions

## Method

I explored each map as a normal player, then repeated any problem I found. Each report includes:

1. Location
2. Steps to reproduce
3. Expected result
4. Actual result
5. Severity
6. Regression check

## Exit criteria

A pass is complete when every major route has been walked, at least one full round has been completed, disaster combinations have been checked, and every high-severity issue has clear reproduction steps.
